# Board Tile assets

Assets provisórios do cartão Trello `[N1] Produzir tabuleiro e casas provisórias`.

- Fonte: [Queen's Trial — N1 Board Tiles](https://www.figma.com/design/oYd1TDvnxXp5g03mUON8K7)
- Tamanho: `80 × 80 px`
- Tons: `light` e `dark`
- Estados: `normal`, `hover`, `selectable` e `selected`
- Produção: SVG carregado pelo Godot
- Revisão: PNG em escala 1×

Os nomes seguem `board_tile_<tone>_<state>.<format>`. A cena de validação é
`res://scenes/board/BoardAssetsTest.tscn`.
